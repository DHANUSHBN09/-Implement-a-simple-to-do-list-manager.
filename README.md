# To-Do List Application (Console-Based)

## 📌 Project Overview
This is a simple console-based **To-Do List Manager** built in Python.  
It allows users to **add, view, and remove tasks**, with all tasks stored in a text file so they remain saved even after closing the program.

This project demonstrates:
- File handling (`open()`)
- Lists and list operations
- String manipulation (`strip()`)
- Basic CLI interaction

---

## 📁 Files Included
- `todo.py` — Main application script  
- `tasks.txt` — Stores all tasks (generated automatically)
